Your masternode rewards, every morning

A phone notification each day with the epoch rewards every XDC masternode you own earned. If a node earned nothing, or the check couldn’t run, you get a loud alert instead, so a quietly failing node doesn’t go unnoticed.

  • Self-hosted
  • Free, no server needed
  • iOS and Android
  • About 10 minutes to set up

Get notifications on your phone

ntfy is a free push notification app. No account needed.

ntfy for iPhone ntfy for Android

Anyone who knows the name can read your notifications, so make it hard to guess. In the app, tap + and subscribe to exactly this name.

Use only letters, numbers, - and _.

Get a free Etherscan API key

Used to list your address’s transactions so they aren’t mistaken for rewards. One key covers XDC.

  1. Sign up at etherscan.io (free).
  2. Open API Keys, click Add, name it and copy the key.

Test it

            
Check everything works now instead of waiting until tomorrow.

Things to know

        

          

            
How rewards are worked out

            
Epoch rewards aren’t ordinary transactions, so they’re inferred, exactly like the Rewards Calculator: the balance change, minus what your own transfers in, transfers out and gas fees explain.

          

          

            
Nothing is missed or counted twice

            
Each run remembers the exact block it stopped at. If a run is late, skipped or fails, the next report simply covers the longer period.

          

          

            
Your details stay yours

            
Your address and API key are stored as encrypted GitHub secrets in your own repository. Notifications show a shortened address, and the saved progress file stores addresses only as hashes.

          

          

            
Want to check a longer period?

            
Use the Rewards Calculator for any date range, such as a financial year. For status changes like standby or slashed, see XDC Tycoon.
